# Meus Projetos

## 3º Semestre

### Empresa Parceira: IPEM-SP (Instituto de Pesos e Medidas do Estado de São Paulo)

**Squad: Tech**

**Problema:**

O projeto teve como objetivo solucionar as dificuldades relacionadas ao gerenciamento de frotas e chamados de serviço do IPEM-SP. O instituto precisava de um sistema centralizado para organizar solicitações de veículos, registros de viagens, quilometragem, manutenções e aprovações de utilização dos veículos oficiais. Também era necessário estabelecer controle de usuários, permissões e fluxos de atendimento.

**Solução Entregue pela Equipe:**

A equipe desenvolveu uma aplicação para centralizar e modernizar o gerenciamento de frotas e chamados de serviço, permitindo registrar solicitações de veículos, acompanhar viagens e comunicar necessidades de manutenção. O sistema também contemplou regras de negócio para aprovação de solicitações, controle de acesso e organização dos fluxos operacionais.

* Git e GitHub: utilizados para versionamento e colaboração no código.
* Figma: utilizado na prototipagem das interfaces.

## 2º Semestre

### Projeto Acadêmico: Sistema de Acompanhamento de Trabalhos de Graduação (TG)

**Squad: Sambold**

**Problema:**

O projeto surgiu da necessidade de centralizar e facilitar o acompanhamento das entregas de Trabalhos de Graduação (TG), envolvendo estudantes, orientadores e coordenação. O processo de entrega de documentos exigia maior organização dos prazos, acompanhamento do status dos trabalhos e acesso aos feedbacks, tornando necessária uma plataforma que reunisse essas informações.

**Solução Entregue pela Equipe:**

A equipe desenvolveu uma aplicação para organizar o processo de entrega e acompanhamento dos Trabalhos de Graduação. O sistema permitiu centralizar o envio de documentos, consultar o andamento das entregas e facilitar o acompanhamento das atividades por estudantes e orientadores, contribuindo para uma gestão mais organizada dos trabalhos acadêmicos.
